# @erp/ui Changelog

All notable changes to the design system package are documented here.  
Format follows [Keep a Changelog](https://keepachangelog.com/). Versioning follows semver once releases are cut from **Approved** components.

## [0.1.0] — 2026-08-15

### Added

- Phase 0 foundation: Storybook, Vitest, i18n helpers/locales for `ui.*`, registry documentation.
- Initial pre-Approved component set (primitives, DataTable, Form shell, overlays, layout).

### Notes

- Public APIs are **not frozen**. Breaking changes require management sign-off once a component is **Approved** in `docs/REGISTRY.md`.
